# Diretrizes do Agente — Área de Membros — Mapa do Prazer Masculino (Brasil)

Este repositório contém o código-fonte da área de membros de produção de `mapa-prazer-masculino-br`.

## Regras de Operação

1. **Deploy e Domínio:** Todo push na branch `main` gera deploy automático no Vercel para `https://mapa-do-prazer-area.vercel.app/#dashboard`.
2. **Preservação de Conteúdo:**
   - Não alterar IDs de vídeos do VTURB sem confirmação.
   - Não alterar caminhos de download dos e-books/assets já entregues às alunas.
3. **Orquestrador:** Este repositório é gerenciado e sincronizado a partir do control plane `group-jevo-funnel-ops` em `members-areas/mapa-prazer-masculino-br/`.
